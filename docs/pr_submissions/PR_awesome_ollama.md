# Pull Request: Add PocketLLM Lite to Mobile Apps section

## Description
This PR adds [PocketLLM Lite](https://github.com/PocketLLM/pocketllm-lite) to the **Mobile Apps** section of `awesome-ollama`.

PocketLLM Lite is an open-source, privacy-first mobile client (Android) designed for local LLM inference and seamless streaming connection to local/remote Ollama endpoints.

## Proposed Entry
```markdown
* [PocketLLM Lite](https://github.com/PocketLLM/pocketllm-lite) - An open-source, offline-first mobile client for Ollama & local GGUF models with local RAG, SKILL.md plugins, and native agent tool execution.
```

## Features Highlight
- **Ollama Streaming & On-Device GGUF**: Connects to local Ollama servers or runs GGUF models directly on-device.
- **DeepSeek R1 Thinking Accordion**: Native rendering of `<think>` reasoning blocks.
- **SKILL.md Plugin Architecture**: Standard open format for custom agent skills with `/` autocomplete.
- **Offline STT & TTS**: Voice-type and read responses aloud without cloud dependencies.
- **Privacy First & Ad-Free**: Zero telemetry, zero tracking, MIT licensed.
